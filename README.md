## Featured Projects

### [Dashboard](https://github.com/nikmahla/Dashboard)

An admin dashboard built with Next.js and TypeScript, featuring:

- Role-based access control for admin and viewer users
- JWT-protected routes
- Interactive charts and data tables
- Light and dark themes
- Unit tests with Jest and React Testing Library
- Accessibility tests with jest-axe
- Continuous integration with GitHub Actions

### Shortlist – Job Search Agent(https://github.com/nikmahla/Job-search-agent)

A Node.js tool that filters, deduplicates, and ranks job listings, then analyzes the best matches using a local LLM (Ollama / Qwen). It also records why each listing was kept or rejected.

[Live Demo](https://job-search-agent-ai.vercel.app/)

### [Annahal Shop](https://github.com/nikmahla/annahal-shop)

An e-commerce demo built with Next.js App Router, JavaScript, Zustand, Tailwind CSS, and Material UI.

Features include product search and filtering, product detail pages, a shopping basket, and favorites saved in localStorage.

[Live Demo](https://annahal-shop-bn2l.vercel.app/)
